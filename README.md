# Custom-Cassette-Tape-Button-Mod

Hello~!
*Again, please back up your save file before downloading/using. I really am not sure if it's like, 100% safe with no problem at all. I've tested it, but just to be sure ; Please back up your save file.

Most of the things you want to change is in "ReplaceTapeStuff"
I've compressed 2 files that are just pictures (around like, 100 of them), you may need to decompress those 2 files before using this.

If you want to add new a new tape for the recording part, you may want to take a look at Recording.gd ; 
For the tape Ui part, go take a look at TapeButton(Replacement).gd

In the files, there are several unused things that are prepared for an upcoming, slightly bigger mod I'm making. Don't worry about those-

Idea :
Since Tape button seems to be rather hard-coded (there seems to be no working around without changing the base code) I've had this idea to allow compatibility between mods :
Uploading the source files, everyone could make an edit to the Tape list and combine two lists of different mods together. That way, despite the replacing codes required, there could technically be some sort 
of compatibility available with a third version that includes both mods. 

*File names :
Since there are quite a few files linked to the tape button, changing any file names originally there might mean rewiring the entirety of the mod. (Learnt this the hard way when I tried to separate this mod from the other 
mod I'm making)

Tape list :
Since sometimes, both conditions could be met, if you want a tape Ui to show even if some other conditions already met, you may want to place your code at the bottom right above the normal texture.
List : Black-Shucks > Optical > Air > Astral > Beast > Thunder > Fire > Earth > Ice > Metal > Plant > Plastic > Poison > Water > Chrome

Lastly, the recording part functions as it adds a sticker during the successful record stage ;
Whereas the Tape Buttons are determined by either if there is a move or a special tag for a tape/mosnterform.
